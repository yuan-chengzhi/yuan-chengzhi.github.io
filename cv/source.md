### ContextSwarm：FLT 证明进展分析与系统迭代

第三作者｜投稿 ICLR 2027

*Are We Ready for Proof Weaving? Understanding Agent Swarms through Fermat's Last Theorem*

- 结合 FLT 证明结构、共享证明状态（ProofState）与运行轨迹，判断局部成果能否满足上层证明的前提及接口。团队形成协作系统与含 **10 项**分层 Lean 重建任务的 FLTBench，整体 FLT 形式化目标尚未完成。

- 整理《设想的长程证明推进方式》，**从上层用途明确局部接口**，让子问题随实际缺口展开；据此参与提示词重构，减少固定检查顺序和强制拆分，保留可靠验证约束。

- 定位并推动补齐**父路线反查**接口，团队合并后专项验收观察到 Agent 能获取上层用途；处理 FLTBench 资料的检索与分段读取，探索 CPS 共享记录与多个数学节点的双向关联。

### FLT 大规模运行的协作过程与证据分析

第三作者｜投稿 AAMAS 2027

*What Can the Next Agent Build On? Proof Weaving in an FLT Campaign*

- 分析同一 FLT 项目的系列运行记录（团队累计约 **100B tokens、40,000 agent-hours**），参与以证明对象、候选版本、共享记录与验证事件为线索重建过程，按**事件发生时的状态**核对证据。

- 分别核查候选修改、反馈送达与后继采用的证据，将衔接缺口整理为**案例与个人诊断文档**；参与证明依赖、Agent 活动、验证状态的可视化，以及稿件校对与修订。
